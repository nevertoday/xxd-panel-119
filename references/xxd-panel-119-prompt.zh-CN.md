# Panel 119 交付适配器

每次生成前完整读取 `original-prompt/zh-CN.md`，它是唯一审美权威。阅读译文不能替代运行时原文。

- 输入：单张原始照片或独立目录批处理。不得二次处理其他 Panel、样张或中间风格化结果。
- `top-bottom`：整张画布仅两个全宽区域，上方照片、下方纺织拼贴，严格 50:50。
- `left-right`：仅覆盖原文上下交付方向；整张画布仅两个全高区域，左方照片、右方纺织拼贴，严格 50:50。任一半内部不得再上下分割。
- `design-only`：纺织拼贴铺满画布，原图仅作不可见参考。
- `wallpaper-pack`：手机、iPad、桌面、手表完整纺织壁纸；明确 `linked` 或 `independent` 及各端尺寸。
- 尺寸：`auto`、`source`、常见或自定义比例、准确像素；生图前明确。
- 文字：`prompt`、`exact`、`none`；明确目标语种。生成文案应少量且对应原图，准确文字逐字保留，无字模式排除所有可见文字及伪文字。
- 完整中文原文之后仅追加选定模式、尺寸、文字与用户明确的非风格需求；每张对照图单轮整张生成。
- 保持选择性提炼、少量大块层叠布片、棉麻纤维、毛边贴布、少量手工针迹、2–4 种鲜活温暖原图取色和超大量留白，不添加外部风格规则。
- 最终 PNG 使用防重名文件名，平铺保存至一个新任务目录；检查严格中线、身份、布艺触感、留白和文字，清理 AI 元数据后交付。
